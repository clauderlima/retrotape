# Functional Baseline

## Purpose

This document records the first hardware-validated RetroTape firmware baseline.
It is the recovery point that must remain available while the codebase, user
interface, documentation, and tape format support are refactored.

## Baseline status

- Date: June 9, 2026
- Target board: ESP32-2432S028 / Cheap Yellow Display
- Display module marking: TPM408-2.8
- Display controller profile: ILI9342 through LovyanGFX
- Resolution and orientation: 320 x 240 landscape
- Touch controller: XPT2046
- Storage: microSD
- Audio output: ESP32 DAC2 on GPIO 26 through the onboard SC8002B amplifier
- Build system: PlatformIO with Arduino Framework

## Hardware-validated ZX/TK90X configuration

The following settings successfully loaded a TAP file on the tested TK90X:

| Setting | Validated value |
| --- | --- |
| TAP timing | 100.0% |
| TAP output level | 31% |
| TAP polarity | Normal |
| Pilot pulse | 619.4 us |
| Sync pulse 1 | 190.6 us |
| Sync pulse 2 | 210.0 us |
| Bit 0 half-pulse | 244.3 us |
| Bit 1 half-pulse | 488.6 us |
| Inter-block pause | 1000 ms |

TAP edges are generated by an ESP32 hardware timer running at 10 MHz. The
interrupt schedules edges against the timer's absolute timeline so normal ISR
latency does not accumulate in every pulse.

## Tested TK90X modification

The tested TK90X only loaded successfully after capacitor **C5 on the TK90X
mainboard** was replaced with a **100 uF capacitor**.

This is a modification to the tested computer, not to the RetroTape board or
its external audio cable. Other TK90X revisions may not require it. Capacitor
polarity and the original circuit must be checked before applying the same
modification to another machine.

## External audio connection used during development

The CYD speaker connector is the bridged output of the onboard amplifier. Both
P4 terminals are active outputs, so neither P4 terminal is board ground.

The documented single-ended test connection is:

```text
one P4 output -> coupling capacitor -> series resistor -> computer EAR input
CYD board GND -----------------------------------------> computer signal ground
other P4 output: leave disconnected
```

The exact external capacitor and resistor arrangement must be recorded with
each hardware test. Do not connect the unused bridged output to ground.

## Functional scope included in this baseline

- 320 x 240 touch user interface
- Home, file browser, player, settings, TAP settings, and Wi-Fi screens
- Platform-root navigation for TK90X/ZX, MSX, and WAV
- WAV PCM playback
- Standard ZX Spectrum TAP playback
- MSX CAS playback
- Play, Stop, elapsed time, duration, and progress display
- microSD directory creation and filtered file browsing
- Wi-Fi network scan, on-screen password entry, saved credentials, and
  fallback access point
- HTTP upload and file listing for `.tap` and `.cas` files

## Baseline protection rules

The following areas require explicit hardware regression testing after any
change:

1. TAP timer initialization and shutdown.
2. TAP ISR edge scheduling.
3. Direct DAC register writes.
4. Standard ZX pulse constants.
5. SD access while starting or changing TAP blocks.
6. Display and touch activity during TAP playback.

Visual refactoring must not change TAP pulse generation as a side effect.
Structural changes to the audio implementation should be performed in small,
independently testable steps against this baseline.
